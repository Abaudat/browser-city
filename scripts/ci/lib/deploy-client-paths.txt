# hand:
#   - .github/workflows/deploy.yml's `changes` job builds a git pathspec
#     from these lines (the `/**` suffix stripped -- a plain directory
#     pathspec already means "everything under it" to `git diff`) to
#     decide whether `deploy-client` needs to run.
#   - .github/workflows/ci.yml's own `client:` paths-filter is checked by

#     gates client-check/client-build/e2e on server/**, scripts/**, etc.,
#     which decide whether those *jobs* run, not whether the deployed
#     asset itself changed), so the direction being checked is one-way:
#     every line here must appear in ci.yml, not the reverse.
#
# Blank lines and #-comments are ignored by both readers.
